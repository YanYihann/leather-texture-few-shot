# Saved-prediction reanalyses

`fixed727/` is the original October 31 companion, now included in version 2.1.0. Its historical README correctly describes it as additional to 2.0.0. Original companion files are preserved unchanged. The analysis uses common query identities and reports all four specified contrasts. It remains exploratory, conditional and unadjusted for multiplicity.

Run `python current/verify_fixed727.py` for standard-library point-estimate and alignment checks. The original NumPy replay command in the companion also reconstructs its recorded conditional intervals. Neither command trains or runs a model.

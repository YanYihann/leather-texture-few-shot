# Results

This folder contains compact result files used to revise the manuscript. The files are provided so that readers can compare regenerated outputs against the reported tables and figures.

The most relevant summary files are:

- `results_independent_filtered_multiseed/independent_multiseed_summary.csv`
- `results_spatial_validation_multiseed/spatial_validation_multiseed_summary.csv`
- `revision_tables/full_ablation_summary.csv`
- `revision_tables/additional_baselines_summary.csv`
- `revision_tables/robustness_compact_summary.csv`
- `revision_tables/resnet_dinov2_discrepancy_summary.csv`
- `revision_tables/open_set_holdout_summary.csv`

Prediction-level CSV files are included when they are small enough for ordinary GitHub hosting.

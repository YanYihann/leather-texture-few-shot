# Dataset

The leather texture dataset is deposited on Zenodo:

https://doi.org/10.5281/zenodo.20736326

Download and extract the archive, then place the folders here:

```text
data/
  my_dataset_1/
  dataset_train/
  dataset_val/
  my_dataset_test_filtered/
```

Folder meanings:

- `my_dataset_1`: original one-reference-image-per-class library;
- `dataset_train`: reference/training split generated from the source images;
- `dataset_val`: controlled spatial validation split generated from non-overlapping image regions;
- `my_dataset_test_filtered`: filtered real independent test set used in the manuscript.

The independent test set used in the paper is composed of real images and is not generated by image augmentation.
